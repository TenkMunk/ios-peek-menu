# Changelog

## 2.2.0

- Bubble-focused message preview and contextual action cards
- Floating reaction shortcuts and configurable haptics
- Optional slide selection, with scrolling on compact screens
- Configurable backdrop blur, spring motion, and reduced-motion mode
- Copyable diagnostics and fallback to Telegram's native menu when the custom menu cannot open
- Compatibility declared for exteraGram 12.5.1+ and SDK 1.4.4.3+
